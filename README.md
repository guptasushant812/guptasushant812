## 🚀 About Me

Hey there! I'm **Sushant Gupta**, a Full-Stack Web Developer with a strong interest in frontend development and UI/UX design. I enjoy turning ideas into practical web applications, solving real-world problems, and creating digital experiences that are both visually appealing and easy to use.

My development journey has given me hands-on experience building responsive websites, interactive interfaces, and full-stack applications. During my time as a .NET Developer Intern at **nGauge (Prometheus Solutions)**, I worked on 11+ client projects, developing frontend interfaces, backend features, and database operations.

🎨 I enjoy exploring UI/UX design, creating clean interfaces, and making web applications work smoothly across different screen sizes and devices.

⚙️ My interests span the entire development process, from designing user interfaces and building frontend experiences to developing backend functionality and working with databases.

🤖 I'm also interested in AI integration, prompt engineering, and exploring new technologies that can make software development more useful and efficient.

💡 I believe technology is most meaningful when it solves real problems. I enjoy learning, experimenting with ideas, and building projects that turn those ideas into useful solutions.
